# Construction Supplies — Store App

> Interactive app prototype for construction supply stores, featuring a stage-based catalogue and a material quantity calculator.

`HTML5` · `CSS3` · `JavaScript` · `Tailwind CSS (CDN)`

## 🇬🇧 English

**Segment:** Construction & home improvement

Interactive app prototype for construction supply stores, featuring a stage-based catalogue and a material quantity calculator.

**Highlights**

- Catalogue organised by construction stage
- Material calculator for paint and flooring by m²
- Seasonal promotions and jobsite delivery

**Tech:** HTML5, CSS3, vanilla JavaScript, Tailwind CSS via CDN.

**Run it:** Open `index.html` in any modern browser — no build step, no dependencies to install.

_This is a design prototype: data is mocked in the front-end and there is no back-end._
